제공하는 기능

TaskDo는 일정·할 일·목표·루틴·브레인 덤프와 독립 메모, 로컬 저장·백업 기능을 제공합니다. 기능과 지원 운영체제는 다운로드 페이지와 릴리스 안내를 기준으로 합니다.

현재 공개 파일은 0.10.2 미리보기입니다. Mac은 Apple Silicon, Windows는 x64 배포본을 제공합니다. Windows 실행·Store 결제·실제 두 기기 동기화와 OS별 동작은 추가 검증 중입니다. macOS 공증과 Windows 코드 서명은 아직 완료하지 않았습니다.

무료 기능과 Pro 기능

현재 배포본의 기본 로컬 기능은 별도 구매 없이 사용할 수 있습니다. Google Drive 동기화는 유효한 Pro 이용권과 설정에서 완료한 Google 로그인이 모두 필요한 유료 기능으로 준비 중이며, 현재 다운로드에서 구매·활성화할 수 없습니다.

Windows Pro는 Microsoft Store 추가 기능, Mac Pro는 웹 구매에 대응하는 서명 라이선스 방식으로 제공할 예정입니다. 가격·판매 시점·이용 기간·환불 조건은 실제 판매 전에 해당 상품과 결제 화면에 안내합니다. 이 페이지에는 결제 기능이 없으며 다운로드나 Google 로그인만으로 결제되지 않습니다.

추후 판매 시 결제 채널의 상품 조건과 정책이 적용되며, 관계 법령이 보장하는 소비자 권리는 제한하지 않습니다. Mac과 Windows의 이용권을 서로 교환하거나 모든 플랫폼에서 공동 사용하는 권리는 별도로 안내하지 않는 한 제공하지 않습니다.

데이터와 백업

사용자가 작성한 일정·메모 등 콘텐츠의 권리는 사용자에게 있습니다. TaskDo는 콘텐츠를 저장·표시하고 사용자가 선택한 동기화·백업을 수행하는 데 필요한 범위에서만 처리합니다. 자세한 내용은 개인정보처리방침을 따릅니다.

삭제·기기 교체·재설치·업데이트 전에는 필요한 자료를 백업해 주세요. 동기화는 별도 백업을 대체하지 않습니다. 현재 자동 동기화는 메모 첨부 이미지를 포함하지 않으며 전체 ZIP 백업에는 현재 참조 이미지가 포함됩니다.

Google 연결과 사용량

Google 기능에는 본인 계정과 필요한 권한이 필요합니다. Google의 장애, 저장 공간, 요청 할당량 또는 권한 철회로 연결이 중단될 수 있습니다. TaskDo는 사용량 제한에 도달하면 전송을 보류하고 로컬 기록을 유지하도록 설계되어 있습니다.

동기화는 Google 계정당 최대 2대의 등록 기기를 기준으로 합니다. 기기별 요청 예산, 지원 데이터 크기와 동기화 주기는 릴리스에 따라 달라질 수 있습니다. 별도 운영 서버 없는 앱 자체 제한만으로 외부 서비스의 과금이나 악의적 우회를 완전히 통제한다고 보장하지 않습니다.
