이 방침은 TaskDo 데스크톱 앱과 이 홈페이지에서 어떤 정보를 처리하고, 어디에 보관하며, 사용자가 어떻게 삭제할 수 있는지 설명합니다. 기본 로컬 기능에는 Google 로그인이 필요하지 않습니다.

처리하는 정보와 목적

정보목적과 보관 위치
일정, 할 일, 목표, 루틴, 브레인 덤프, 회고와 메모사용자가 작성한 내용을 앱에 표시·저장합니다. 기본적으로 사용자의 기기 내 TaskDo 데이터 폴더에 보관합니다.
메모 첨부 이미지, 창 위치·크기·불투명도 등 설정메모 표시와 기기별 환경 복원에 사용하며 기기에 보관합니다. 첨부 이미지는 현재 Google Drive 자동 동기화 대상이 아닙니다.
Google 이메일과 계정 고유 식별자(sub)사용자가 설정에서 Google 로그인한 경우 계정 식별, 다른 계정 간 데이터 혼합 방지 및 라이선스 확인에 사용합니다. 기기의 앱 데이터에 보관합니다.
Google 인증 토큰허용한 Google 기능에 접근할 때 사용합니다. 액세스 토큰은 메모리에, 갱신 토큰은 macOS Keychain 또는 Windows Credential Manager에 보관합니다.
설치·작업 공간 식별자, 동기화 변경 기록, 요청 사용량기기 구분, 충돌 처리와 사용량 제한에 사용하며 로컬 저장소에 보관합니다. 동기화가 활성화되면 공유 데이터에 필요한 식별자와 변경 정보도 Drive에 저장합니다.
이용권 상태와 서명된 라이선스Pro 기능 사용 권한 확인에 사용합니다. Mac 라이선스에는 Google 계정 식별자·제품·플랫폼·발급 및 만료 정보가 포함되며 기기와 본인 Drive에 보관할 수 있습니다. Windows 이용권은 Microsoft Store를 통해 확인합니다.
문의 이메일에 포함한 주소와 내용사용자가 직접 문의한 경우 답변과 문제 해결에 사용합니다. 문의 처리가 끝나고 보관할 이유가 없어지면 삭제합니다. 비밀번호나 인증 토큰은 보내지 마세요.

Google 데이터의 사용

TaskDo는 로그인에 openid와 email 권한을, 앱 전용 Drive 저장에 https://www.googleapis.com/auth/drive.appdata 권한을 사용합니다. 사용자의 일반 Drive 파일 전체, Gmail, 연락처 또는 Google Calendar를 읽는 권한을 요청하지 않습니다.

동기화를 활성화하면 일정·목표·루틴·기록·메모 본문과 필요한 변경 정보가 사용자의 Google Drive 앱 전용 공간에 전송됩니다. 라이선스 등록·복원도 이 공간을 사용합니다. 현재 배포본은 판매 설정 준비 중이며, 유효한 이용권과 Google 로그인 조건을 충족해야 일정·메모 데이터 동기화가 활성화됩니다.

미결제 상태에서도 사용자가 시작한 로그인과 라이선스 확인·등록은 가능합니다. Google 계정 연결만으로 자동 결제되지 않습니다.

TaskDo가 Google API에서 받은 정보를 사용하거나 다른 앱으로 이전하는 행위는 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 데이터는 광고, 판매, 대출 심사 또는 범용 AI 모델 학습에 사용하지 않습니다.

전송과 제3자 서비스

현재 TaskDo 운영자는 일정·메모 원문을 수집하는 별도의 동기화 서버를 운영하지 않습니다. Google 기능을 사용하면 인증·계정 확인·동기화 요청이 Google에 전송됩니다. 해당 정보에는 Google의 처리방침도 적용됩니다.

이 홈페이지와 배포 파일은 GitHub Pages·GitHub Releases에서 제공합니다. 이 사이트는 별도의 분석 도구, 광고 스크립트, 로그인 폼이나 추적용 쿠키를 추가하지 않습니다. 글꼴과 앱 화면 이미지도 이 사이트에서 제공합니다. GitHub는 호스팅·보안·다운로드 제공을 위해 IP 주소와 요청 기록 등을 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.

AI 회고는 사용자가 자료를 복사해 ChatGPT 등 외부 서비스에 직접 전달하는 방식입니다. TaskDo가 자동 전송하지 않으며, 사용자가 전달한 정보에는 해당 서비스의 정책이 적용됩니다.

보관과 삭제

  • 로컬 기록은 사용자가 삭제하거나 앱 데이터 폴더를 삭제할 때까지 기기에 남습니다. 앱 삭제만으로 문서 폴더, 백업, OS 자격 증명 저장소 또는 Drive 파일이 모두 삭제되지는 않습니다.
  • 로그아웃하면 기기의 Google 갱신 토큰을 삭제하고 자동 Drive 요청을 중단합니다. 로컬 기록·백업·일부 계정 연결 식별자·라이선스와 Drive에 보관한 파일은 유지됩니다.
  • Google 접근 권한은 Google 계정의 서드 파티 연결 관리에서 철회할 수 있습니다. 권한 철회와 이미 저장된 로컬·Drive 데이터 삭제는 서로 다른 동작입니다.
  • Drive 앱 데이터는 Google Drive 설정의 앱 관리에서 TaskDo에 연결된 앱 데이터를 삭제하는 방법으로 제거할 수 있습니다. Drive 앱 데이터를 지우면 클라우드 복원용 기록과 라이선스도 사라질 수 있습니다.
  • 전체 삭제가 필요하면 앱을 종료한 뒤 문서의 TaskDo 데이터 폴더와 직접 보관한 ZIP·DB 백업, OS 로컬 앱 데이터의 TaskDo 폴더 및 TaskDo Google 자격 증명을 함께 확인하세요. 사용자 파일을 지우기 전 필요한 백업을 보관하세요.

보호와 사용자 선택

Google 토큰은 OS 자격 증명 저장소를 사용하고, 네트워크 요청은 HTTPS로 전송합니다. 일정·메모 DB와 내보낸 백업에는 앱 자체의 암호화나 종단간 암호화가 적용되지 않습니다. 기기 접근 권한과 백업 공유에 주의해 주세요.

기본 로컬 기능은 로그인 없이 사용할 수 있습니다. Google 로그인을 하지 않거나 권한을 철회해도 로컬 데이터는 유지됩니다. 운영자가 기기·Drive 안의 기록을 직접 열람하거나 대신 삭제할 수는 없습니다. 문의 내역 등 운영자가 보유한 정보의 확인·정정·삭제는 아래 이메일로 요청할 수 있습니다.
