# TaskDo 홈페이지

GitHub Pages용 정적 홈페이지, 개인정보처리방침과 이용약관. 앱 소스는 포함하지 않는다.

- 홈페이지: https://ghdic.github.io/taskdo-web/
- 개인정보처리방침: https://ghdic.github.io/taskdo-web/privacy/
- 이용약관: https://ghdic.github.io/taskdo-web/terms/
- 다운로드: https://github.com/ghdic/taskdo-web/releases
- 문의: ghdic77@gmail.com

추가 설치나 빌드가 없다. Pages 소스는 main 브랜치의 저장소 루트다. 이미지·Pretendard 글꼴은 자체 호스팅하고 별도 분석·추적을 추가하지 않는다. .nojekyll은 Jekyll 처리를 생략한다.

다운로드 링크는 검증된 v0.10.0 자산 이름으로 고정한다. 미리보기이므로 releases/latest 링크를 사용하지 않는다. 앱 릴리스는 Git에 ZIP을 추가하지 않고 GitHub Releases에 업로드한다.

Google OAuth 설정과 도메인 검증은 OAUTH_SETUP.md를 참고한다.
